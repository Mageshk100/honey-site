# 🍯 Honey E-Commerce Website

A modern, responsive e-commerce website developed as a **freelance project in collaboration with a college senior**. The platform provides an intuitive online shopping experience with product browsing, weight-based product variants, cart management, shipping calculations, and checkout functionality.

## Project Overview

* **Project Type:** Freelance Project
* **Role:** Frontend Development
* **Collaboration:** College Senior
* **Technologies:** React.js, Vite, Tailwind CSS, React Router, Lucide React

## Key Features

### 1. Home Page

* Responsive navigation bar with product search and cart indicator.
* Hero section highlighting honey products.
* Featured products and product categories.
* Brand story, customer testimonials, and contact information.
* Newsletter subscription section.

### 2. Product Listing & Details

* Responsive product grid with search, filtering, and sorting.
* Product details with image galleries and descriptions.
* Weight-based variants with dynamic pricing.
* Quantity selection and related product recommendations.

### 3. Shopping Cart

* Add, remove, and update product quantities.
* Automatic subtotal and shipping calculations.
* Coupon code application and discount calculation.
* Persistent cart data using localStorage.

### 4. Checkout & Order Management

* Customer details and delivery address validation.
* Shipping charges calculated according to order value and destination.
* Cash on Delivery order placement.
* Order confirmation page with order details.
* Printable invoice and WhatsApp order enquiry.

### 5. Additional Features

* About Us and Contact pages.
* FAQ and product information sections.
* Shipping, refund, privacy, and terms pages.
* Responsive layouts for desktop, tablet, and mobile.
* Reusable React components and structured product data.
